# Claude Quest
Player fantasy/audience: Claude Code power users (about 12 hours a day) who want their real work to grow a hero in a Diablo, Path of Exile and RuneScape style idle ARPG, without spending a token or making a single choice.
Main verb and short loop: work in Claude. Edits, reads, shell, agents, turns and commits bank Focus; Focus is combat time; the hero fights, loots, equips and levels. Out of Focus, the hero camps: Fishing, Mining and Archaeology gather, Cooking, Smithing and Alchemy process, each with a small permanent combat perk.
Meaningful choices and intended feeling: none by design. The feeling is "my work made this happen": a long, steady grind that rewards real habits (commits summon goblins, green tests light shrines, early compaction earns Well Rested).
Reference lessons and differentiation: Diablo (loot rarity, sets, legendary powers, acts then endless maps), Path of Exile (currency orbs, atlas tiers, keystones), RuneScape (the XP curve and life skills where 92 is half of 99). Different because it is fed by real Claude work and costs nothing to run.
First playable and success/failure/restart: shipped as v0.1.0. Death sends the hero back to town; nothing is lost but time. Deleting `~/.claude/claude-quest/` restarts.
Platform/input/hardware: Claude Code desktop app (animated SVG scene above the prompt and the `/quest` pane) and terminal (one-line ticker). No input.
Non-goals: model calls, player choices, network traffic (until opt-in leaderboards), anything that slows Claude.
Experience hypothesis and disproof: a power user keeps the mod on for months because progress tracks their work and stays meaningful. Disproved if the owner finds it too fast (v0.1: level 70 in about a month), too noisy on screen, or out of things to chase.
